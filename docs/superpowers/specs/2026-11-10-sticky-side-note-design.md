# StickySideNote 设计文档（MVP）

日期：2026-11-10
状态：待 Jimmy 确认

可交互参考原型：同目录下的 `prototype.html`（用浏览器直接打开；外观、动画、手势以它为准）。

## 1. 这是什么，为什么要做

Jimmy 平时把实体便签贴在显示器边框上，写简短的语录和笔记：一是方便随手复制，二是把这几天要记住的东西一直挂在眼前。

StickySideNote 是一个 Mac 桌面 App，把这件事搬到屏幕上：多张彩色小条常驻贴在屏幕左边缘，一眼可见，鼠标移上去看全文，点一下就复制。

现有的 App 要么自由漂浮（macOS 便笺），要么平时藏起来要唤出（SideNotes），没有"常驻可见 + 贴边 + 点一下复制"的组合。

## 2. 目标

- 便签常驻显示在屏幕左边缘，浮在所有窗口之上，随时看得到。
- 收起时几乎不占空间、不挡工作区。
- 看全文只需把鼠标移上去；复制只需点一下。
- 新建、修改、换色、删除都在便签上就地完成，不需要打开主窗口。
- 重启电脑后便签还在。

## 3. 不做的（MVP 范围外）

- 同步、iCloud、多设备
- 图片、富文本、Markdown、链接识别
- 搜索、标签、分组
- 拖动排序
- 贴在顶部/底部（Jimmy 提过"如果放顶部可以显示前几个字"，留给以后）
- 多块屏幕同时各显示一列
- 提醒、到期时间
- 全局快捷键
- 上架 App Store、签名公证（只在 Jimmy 自己的 Mac 上本地构建运行）

## 4. 反目标（即使功能都对，出现这些也算失败）

- 便签挡住正常工作：收起状态必须只占左边缘一条窄带，窄带以外的区域鼠标点击必须正常穿透到下面的窗口。
- 抢焦点：悬停和单击复制都不能让当前正在用的 App 失去键盘焦点。只有进入编辑时才接收键盘输入。
- 鼠标路过左边缘时便签乱弹、闪烁。
- 丢笔记。

## 5. 外观与行为（Jimmy 已确认）

### 5.1 位置与排列

- 便签贴在屏幕左边缘，竖排一列，从上往下按创建时间排列，新的在最下面。
- 一列的最下方是一个半透明深色的 "+" 小条，用来新建。
- 常驻显示，浮在所有普通窗口之上。

### 5.2 收起状态

- 每张便签是一小块彩色条，约 36 × 52 pt，平面色块、很淡的投影。右侧两个角一大一小（大角约 20 pt 圆弧，小角 6 pt），做成花瓣形；相邻两张的大角上下交替，一列看起来像一串叶子。
- 条上只显示笔记的第一个字符（中文首字、英文首字母大写、emoji 原样）。

### 5.3 悬停展开

- 鼠标移到某张便签上，它向右滑出（约 180 ms 缓出，不回弹、不过冲），宽约 268 pt，右侧角变为 24 / 16 pt，高度随内容自适应，显示全文。
- 展开的便签盖在其他便签和窗口上面，投影加深。
- 底部一行淡色小字提示："单击复制 · 双击编辑"。
- 鼠标移开即收起。

### 5.4 单击复制

- 单击便签：把全文（去掉首尾空白的纯文本）写入系统剪贴板。
- 反馈：便签本身不缩放、不弹跳，底部小字加深并变成"✓ 已复制"，约 1.2 秒后恢复。
- 零延迟。双击编辑时第一下点击也会触发一次复制，这是接受的代价。

### 5.5 新建

- 点 "+"：在列尾出现一张展开的空便签，直接进入编辑状态。颜色按 sky → cyan → lavender → coral → gold → sun 自动轮换（由冷到暖）。"+" 小条是靛蓝底、白色加号，悬停和按下时颜色加深。

### 5.6 编辑

- 双击便签进入编辑，便签保持展开，靛蓝描边加一圈淡靛蓝光环表示正在编辑，底部小字变成"Esc 或点别处保存"。
- 纯文本、可多行（回车换行）。粘贴进来的内容一律当纯文本。
- 按 Esc 或点便签以外的地方：保存并收起。
- 保存时内容为空（或全是空白）：这张便签被删除。

### 5.7 右键菜单

- 六个颜色圆点（点一下换色）+ "删除便签"。用系统原生菜单的外框（Claude 的决定：比原型里自绘的白色卡片省事，也更像 Mac），圆点一行放在菜单最上面。

### 5.8 视觉风格

配色、圆角、投影和动效用下面这一套固定取值。

便签底色用六个花瓣色（pastel 档），文字一律用 `fg`：

| 令牌 | 底色 |
|---|---|
| `petal-sky` | `#a7cde8` |
| `petal-cyan` | `#4dd0cf` |
| `petal-lavender` | `#c9bfe5` |
| `petal-coral` | `#e59fb1` |
| `petal-gold` | `#f2b33c` |
| `petal-sun` | `#f4d86b` |

其他令牌：

| 用途 | 令牌 | 值 |
|---|---|---|
| 便签文字 | `fg` | `#020617`（不用纯黑，花瓣色上不用白字） |
| 提示小字 | `text-medium` | 文字色 64% 透明度 |
| "+"、编辑描边 | `brand-500` | `#574efa`；悬停 `#463ee0`，按下 `#3a33b8` |
| 编辑光环 | `shadow-focus` | `0 0 0 4px rgba(87,78,250,.20)` |
| 收起投影 | `shadow-sm` | `0 1px 2px rgba(2,6,23,.04), 0 1px 3px rgba(2,6,23,.06)` |
| 展开、菜单投影 | `shadow-lg` | `0 10px 15px -3px rgba(2,6,23,.08), 0 4px 6px -4px rgba(2,6,23,.04)` |
| 圆角 | `radius-sm / md / 2xl / 3xl` | 6 / 8 / 16 / 24 pt，不用其他值 |
| 动效 | `duration-base` + `ease-out` | 180 ms，`cubic-bezier(.16,1,.3,1)` |

硬性约束：

- 字体 DM Sans（400 / 500 / 600 / 700），中文回落到系统的苹方。字体文件随 App 打包（DM Sans，OFL 开源许可）。
- 平面为主：不用渐变、毛玻璃、厚重投影、彩色侧边条。
- 动效只用淡入淡出和短位移；禁止回弹、弹簧、过冲、缩放。
- 界面文字不用 emoji、不用感叹号。

花瓣形的角（右侧一大一小两个圆角、上下交替）是这个 App 自己的造型。

### 5.9 保存与启动

- 便签存在本机，每次改动立即保存，重启后还在。
- App 默认开机自动启动，可以关。

## 6. 我（Claude）做的决定——Jimmy 没有逐条确认，读的时候请检查

技术选型：

- 原生 Mac App：Swift + SwiftUI，窗口层用 AppKit。不引入第三方依赖。本机已有 Xcode 27.2 / Swift 6.4 / macOS 27.2。
- 最低系统版本：macOS 14。

行为：

- **菜单栏图标**：App 没有 Dock 图标、没有主窗口，只在菜单栏放一个小图标，菜单里有：新建便签、隐藏/显示全部便签、开机自动启动（勾选项）、退出。
- **哪块屏幕、哪一边**（2026-11-10 Jimmy 追加）：默认在主屏幕左边缘。按住任意一张便签或 "+" 拖动（移动超过 4 pt 才算拖动，否则仍是单击），整列便签跟着鼠标走；松手后吸附到鼠标所在屏幕较近的左边或右边，高度位置不变。贴在右边时布局镜像：圆角朝左，卡片向左展开。所在屏幕和左右边会记住；那块屏幕被拔掉时暂时回到主屏幕，插回后自动回去。编辑中不能拖动。
- **所有普通桌面空间都显示**。别的 App 全屏时便签隐藏，退出全屏或切回普通桌面后恢复显示（这一条是 Jimmy 决定的）。
- **Dock 放在左边时**：便签贴在 Dock 右侧（系统可用区域的左边缘），不压在 Dock 上。
- **起始高度**：便签列从屏幕可用高度约 13% 处开始往下排。
- **放不下时**：一列排到屏幕底部放不下新的一张时，"+" 隐藏，菜单里的"新建便签"置灰。MVP 不做滚动。（13 寸笔记本大约能放 12 张。）
- **已有便签放不下时**（比如换到更小的屏幕）：按比例缩小每张小条的高度和间距让全部便签都露出来，保证每一张都还能悬停、复制、编辑、删除；不允许有便签被裁掉看不见。
- **安装方式**：交付物包含一个构建并安装到 `/Applications/StickySideNote.app` 的脚本；开机自启动只从这份安装好的 App 注册。
- **原型与本文档不一致时**：外观和手感以原型为准，行为以本文档为准（例如原型把展开高度限制在 260 px，实际按下面"超长笔记"一条）。
- **删除不弹确认**，也没有撤销。
- **超长笔记**：展开高度上限为屏幕高度的 60%，超出部分在展开卡片内可滚动；编辑时同样。
- **首次启动**：自带一张示例便签，内容是"悬停看全文 · 单击复制 · 双击编辑 · 右键换色或删除"。
- **深色模式**：便签颜色不变。
- **存储**：`~/Library/Application Support/StickySideNote/notes.json`，一个数组，每条有 `id`、`text`、`color`、`createdAt`。写入要原子化（先写临时文件再替换），避免写到一半崩溃丢数据。文件损坏读不出时，把坏文件改名备份，从空列表启动，不要覆盖它。

## 7. 留给实现者的

- 窗口怎么实现（一个面板还是每张便签一个面板、层级、怎样做到窄带之外点击穿透、怎样在不激活 App 的情况下响应悬停和点击、编辑时怎样临时接收键盘输入）。只要满足第 4 节的反目标即可。
- 悬停的触发延迟和防抖数值、动画曲线的具体参数——以原型的手感为目标。
- 项目结构、构建方式（Xcode 工程或 Swift Package 均可）、测试方法。
- 菜单栏图标的图形。
- 开机自启动的实现方式。

## 8. 怎样算做完

在 Jimmy 的 Mac 上：

1. 启动 App 后左边缘出现便签列和 "+"，Dock 里没有图标，菜单栏有图标。
2. 在任意 App 的普通窗口里（比如在浏览器里打字时），便签都可见；鼠标移上去展开，移开收起，期间原 App 不失去焦点。把某个 App 切到全屏，便签消失；退出全屏，便签回来。
3. 单击一张便签，切到别处粘贴，得到它的全文。
4. 点 "+" 写一条新的，Esc 保存，首字显示正确。
5. 双击修改、右键换色、右键删除都生效。
6. 退出再打开，便签的内容、颜色、顺序不变。
7. 便签窄带右侧的窗口内容可以正常点击和拖动。
